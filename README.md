# Python Calculator (GUI & CLI)

A clean, robust, dual-mode calculator application built from scratch using Python. This project includes both a Graphical User Interface (GUI) version and a Command-Line Interface (CLI) version.

## Features
- **Dual Mode:** Includes both a visual GUI (Tkinter) and a fast terminal-based CLI.
- **Advanced Operations:** Supports basic arithmetic (+, -, *, /), square root (√), and percentage (%).
- **Error Handling:** Gracefully handles division by zero, invalid inputs, and math errors without crashing.
- **History Tracking:** The GUI version displays the previous calculation on the screen.

## Technologies Used
- **Python 3**
- **Tkinter** (for the GUI)
- **Math module** (for square root calculation)

## What I Learned
Building this project helped me solidify my understanding of:
- **Code Separation:** Keeping the core calculation logic separate from the user interface.
- **Exception Handling:** Using `try-except` blocks to handle user input errors and division by zero.
- **UI/UX Design:** Designing an intuitive button layout for a visual calculator and a clear text flow for the terminal.
- **Lambda Functions:** Using lambdas in Tkinter to pass specific arguments to button commands.

## How to Run

### 1. The GUI Version (Visual)
Open your terminal and run:
```bash
python calculator_gui.py
```

### 2. The CLI Version (Terminal)
Open your terminal and run:
```bash
python calculator_cli.py
```
