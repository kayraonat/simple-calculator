# Python Calculator

A clean, user-friendly calculator application built from scratch using Python. 

##  Features
- Basic arithmetic operations (Addition, Subtraction, Multiplication, Division).
- Input validation to prevent crashes (e.g., handling division by zero).
- Clean and responsive graphical user interface (GUI) using Tkinter.

##  Technologies Used
- **Python 3**
- **Tkinter** (for the GUI)

##  What I Learned
Building this project helped me solidify my understanding of:
- Object-Oriented Programming (OOP) principles (e.g., creating a `Calculator` class).
- Handling user input and exceptions gracefully (Try/Except blocks).
- Designing a functional and intuitive user interface.
